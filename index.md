# NaijaAssets - Helping Nigerian Students Learn Better

Live classes, recorded lessons, and subscription plans for Nigerian students. WAEC, NECO, and JAMB preparation.

## Key Features
- Live online classes with qualified teachers
- Recorded lessons accessible anytime
- Subject subscriptions with monthly billing
- Creator program for student content
- Scholarship programs
- Affiliate program
- Teacher program for educators
